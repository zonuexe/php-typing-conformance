array_is_list() on a keyless tuple shape

Group: Cross-analyzer regressions · Category: regression · File: regressions_keyless_tuple_is_list.php

array{int, string} has implicit sequential integer keys 0 and 1, so it is always a list and array_is_list($t) is always true — the counterpart of the always-false optional-key cases. This records whether each tool treats the keyless tuple as a guaranteed list (reporting the check as redundantly true, or narrowing silently) and confirms consistency with the explicit-key list-ness case.  * `array{int, string}` has implicit sequential integer keys 0 and 1, so it is always a
