String case refinements (lowercase-string, uppercase-string, …)

Group: Advanced PHPDoc types · Category: ecosystem · File: phpdoc_advanced_family_string_case.php

lowercase-string, uppercase-string and their non-empty variants are case-constrained refinements of string. Analyzers that model them reject a literal of the wrong case; others fall back to plain string and accept it.
